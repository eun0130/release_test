# Atlas WBS 크롬 확장 — 설치와 업데이트 안내

## 처음 설치 (한 번만)

1. 본인 **Multimedia** 폴더 밑에 원하는 이름으로 폴더를 하나 만듭니다.
2. 전달받은 `install.vbs` 파일을 그 폴더 안에 넣고 **더블클릭**합니다.
3. "이 폴더에 설치합니다 — 계속할까요?" 창에서 [확인]을 누르면 자동으로 설치됩니다.
4. 크롬 주소창에 `chrome://extensions` 를 입력해 이동한 뒤:
   - 오른쪽 위 **개발자 모드**를 켭니다.
   - **"압축해제된 확장 프로그램을 로드합니다"** 를 누르고 위에서 만든 폴더를 선택합니다.

설치 끝. 툴바에 Atlas WBS 아이콘이 나타납니다.

## 업데이트 (새 버전이 나왔을 때)

1. 아이콘에 빨간 **NEW** 배지가 켜지면 새 버전이 있다는 뜻입니다.
2. 설치 폴더 안 `update.vbs` 를 **더블클릭**합니다. 창은 뜨지 않고,
   완료되면 화면 오른쪽 아래에 알림이 나타납니다.
3. 1분 안에 확장이 스스로 새 버전으로 전환됩니다. 배지가 꺼지면 완료.

새 버전 확인은 하루 한 번(새벽 3시, 꺼져 있었다면 크롬을 처음 켤 때) 자동으로 이루어집니다.
아이콘을 눌러 **지금 확인** 버튼으로 바로 확인할 수도 있습니다.

## 개인 설정 (일반 사용자는 건너뛰세요)

기본 설정은 `config.default.json` 에 있으며 업데이트 때마다 새 버전으로 교체됩니다.
특정 PC에서만 다른 서버 주소를 쓰려면, 같은 폴더에 `config.json` 파일을 만들어
바꿀 항목만 적으면 됩니다. 이 파일은 업데이트해도 절대 덮어쓰지 않습니다.

```json
{
  "apiBase": "https://github.example.com/api/v3",
  "repo": "org/atlasWbs"
}
```
